# Football Pronostic - Backend (Java Spring Boot)

**Football Pronostic** is een mobile app voor het maken en beheren van voetbalvoorspellingen. Deze backend is ontwikkeld met **Java Spring Boot** en biedt REST API’s voor interactie met de frontend.  

---

## Features

- Beheer van gebruikers en teams
- Creëren en beheren van voorspellingengroepen
- Meedoen aan competities en matches
- Real-time ranglijsten
- Public/private groepen voor voorspellingen
- REST API endpoints voor alle functionaliteiten

---

## Technologieën

- **Java 21**
- **Spring Boot**
- **Spring Data JPA** met Hibernate
- **PostgreSQL**
- **Lombok**
- **Docker**
